03 - Actualizar footprints en indice

Documentacion funcional de la etapa que lleva las geometrías de las imagenes cargadas desde el mosaic dataset hacia el indice de vuelos PAO y recalcula el campo Nombre_de_Vuelo.

Objetivo

Esta etapa sincroniza el componente vectorial del flujo. Despues de cargar las imagenes al mosaic dataset, se exportan sus footprints, se adaptan los campos al modelo del feature class de indice y se anexan las nuevas geometrías a la GDB corporativa.

La etapa escribe en una feature class corporativa y puede actualizar el campo NombreVuelo del mosaic dataset. Por eso queda con DRY_RUN = True por defecto.

Flujo

  1. Leer los resultados de carga de la etapa 2.
  2. Seleccionar los registros cargados correctamente o ya existentes en el mosaic dataset.
  3. Consultar si esos Name ya existen en el indice para evitar duplicar geometrías.
  4. Exportar footprints desde el mosaic dataset con ExportMosaicDatasetGeometry.
  5. Renombrar campos de la exportacion para que coincidan con el feature class destino.
  6. Hacer Append hacia el indice de vuelos.
  7. Recalcular Nombre_de_Vuelo ordenando por Name ASC.
  8. Actualizar NombreVuelo en el mosaic dataset usando el valor calculado en el indice.

Mapeo de campos

La exportacion del mosaic dataset trae nombres de campos distintos al modelo del indice. Antes del append se aplican estos renombres:

Campo exportadoCampo destinoUso
FechaAdquiFecha_AdquFecha de adquisicion.
FechaCargaFecha_PublFecha de publicacion/carga.
NombreVueloNombre_de_VueloNombre operativo del vuelo.
ProductNameProductNamIdentificador de producto/ObjectID en el modelo destino.

Nombre_de_Vuelo

La regla replica el notebook 009. Se recorre el indice completo ordenado por Name ASC. Para cada registro con Sector y Fecha_Adqu, se asigna:

NNN_yy_mm_dd_sector

Ejemplo:

001_26_05_08_DME_13
Si se activa RECALCULATE_ALL_NOMBRE_VUELO, el orden se recalcula para todo el indice, no solo para las nuevas imagenes.

Criterio para ejecutar

  1. Ejecutar con DRY_RUN = True.
  2. Revisar 02_names_to_append.csv y confirmar que son las imagenes esperadas.
  3. Cambiar DRY_RUN = False.
  4. Ejecutar append y recalculo.
  5. Validar en ArcGIS Pro que las nuevas geometrías aparecen en el indice.
