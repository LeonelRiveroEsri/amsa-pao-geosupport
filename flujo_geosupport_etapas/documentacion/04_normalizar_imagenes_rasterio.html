04 - Normalizar imagenes con Rasterio

Documentacion funcional de la etapa que genera imagenes normalizadas/cortadas usando los footprints cargados en el indice de vuelos.

Objetivo

Crear una version limpia de cada imagen cargada al datastore, recortada con la geometría de su footprint. El proceso se hace con rasterio.mask para evitar deformaciones observadas con otros metodos de clip.

Por defecto REPLACE_ORIGINALS = False. La etapa genera copias normalizadas para revision. El reemplazo de originales en el datastore debe activarse solo despues de validar visualmente los resultados.

Entradas

EntradaDescripcionUso
02_load_results.csvResultado de carga al mosaico.Entrega los Name y rutas destination_path de las imagenes cargadas.
01_load_input_with_attributes.csvManifest enriquecido de etapa 2.Se usa como respaldo si falta alguna ruta en el CSV de resultados.
CL_MLP_PAO_Indice_Vuelos_PAO_IMGS_POFeature class de footprints.Fuente de geometría para recortar cada raster por Name.
destination_pathRuta del TIF en datastore.Raster que se normaliza.

Flujo

  1. Leer imagenes cargadas desde la etapa 2.
  2. Filtrar registros exitosos si PROCESS_ONLY_SUCCESSFUL_LOADS = True.
  3. Cargar footprints desde el indice usando el campo Name.
  4. Para cada imagen, buscar su geometría de footprint.
  5. Proyectar el footprint al sistema del raster si corresponde.
  6. Ejecutar rasterio.mask.mask con crop=True.
  7. Escribir un GeoTIFF normalizado en la carpeta de salida.
  8. Opcionalmente reemplazar el TIF original en datastore.

Normalizacion Rasterio

ComponenteRegla
rasterio.mask.maskRecorta usando el footprint con crop=True y mascara fuera del poligono.
RGBSi el raster tiene 3 o mas bandas, se toman las primeras 3 como RGB.
Colormap / 1 bandaSi tiene una banda y colormap, se convierte a RGB usando la tabla de colores.
AlphaSe agrega una cuarta banda alpha para transparencia limpia fuera del footprint.
CompresionSe escribe GeoTIFF con compress='deflate' y tiled=True.
Color interpretationSe define como red, green, blue, alpha.
Este enfoque busca que el raster se vea correctamente tanto como item directo como dentro del mosaic dataset.

Reemplazo de originales

El notebook permite reemplazar el TIF original del datastore con la version normalizada. Esta accion esta apagada por defecto.

ParametroValor inicialDescripcion
REPLACE_ORIGINALSFalseSi es True, copia el normalizado encima del TIF original.
CREATE_BACKUP_BEFORE_REPLACEFalseEvita duplicar archivos .bak en datastore. Activar solo si se necesita respaldo.
BUILD_PYRAMIDS_AFTER_REPLACEFalsePermite reconstruir piramides/estadisticas despues del reemplazo.

Criterio para avanzar

  1. Ejecutar con REPLACE_ORIGINALS = False.
  2. Revisar una muestra de los TIF en normalized_tif en ArcGIS Pro.
  3. Confirmar que la visualizacion directa y en mosaico es correcta.
  4. Activar REPLACE_ORIGINALS = True si corresponde.
  5. Revisar 01_normalizacion_rasterio_resultados.csv y confirmar que no hay errores.
