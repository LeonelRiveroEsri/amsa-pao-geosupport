05 - Preparar APRX para publicacion

Documentacion funcional de la etapa que deja el APRX listo para publicar imagenes referenciadas como capas raster fuera del Image Server.

Objetivo

Agregar al APRX las imagenes nuevas como capas raster directas, ubicarlas dentro del grupo operativo correcto, renombrarlas y ordenarlas para que queden listas para revision/publicacion.

Por defecto se guarda una copia de revision del APRX con saveACopy. El APRX original solo se guarda si SAVE_ORIGINAL_APRX = True.

Entradas

EntradaDescripcionUso
02_load_results.csvResultado de etapa 2.Entrega las rutas destination_path de las imagenes cargadas.
APRX_PATHRuta del APRX operativo PAO.Proyecto base donde se agregan y ordenan las capas.
MAP_NAMEMapa dentro del APRX.Mapa donde existe el grupo de imagenes drone.
Vuelos Drone PAO > Imagenes DroneGrupo destino.Las capas raster se insertan como hijas directas de este grupo.

Flujo

  1. Leer las imagenes cargadas desde etapa 2.
  2. Abrir el APRX con arcpy.mp.ArcGISProject.
  3. Buscar el mapa y el grupo Vuelos Drone PAO > Imagenes Drone.
  4. Detectar capas ya existentes en el grupo para evitar duplicados.
  5. Agregar las imagenes faltantes con addDataFromPath y addLayerToGroup.
  6. Remover la capa temporal agregada fuera del grupo.
  7. Renombrar capas quitando CL_MLP_PAO_IF_Ortho_ y .tif.
  8. Ordenar de fecha mas nueva a mas vieja.
  9. Guardar copia de revision o APRX original segun parametros.

Renombrado

El nombre visual de la capa se simplifica para publicacion:

CL_MLP_PAO_IF_Ortho_26_05_08_DME_13.tif -> 26_05_08_DME_13

Tambien se limpian nombres temporales con prefijo tmp_.

Orden

El orden se calcula desde el patron yy_mm_dd_sector. Las capas quedan de mas nuevas a mas viejas dentro del grupo Imagenes Drone.

El orden se aplica solo a las capas raster hijas directas del grupo, para evitar mover otros grupos o capas del mapa.

Criterio de validacion

  1. Ejecutar con SAVE_COPY_FOR_REVIEW = True y SAVE_ORIGINAL_APRX = False.
  2. Abrir la copia de revision en ArcGIS Pro.
  3. Validar que las capas quedaron dentro de Vuelos Drone PAO > Imagenes Drone.
  4. Validar nombres sin prefijo ni extension.
  5. Validar orden de mas nueva a mas vieja.
  6. Si todo esta correcto, decidir si se guarda el APRX original o se usa la copia para publicacion.
