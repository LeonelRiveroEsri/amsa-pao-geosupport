Checklist recomendado del flujo GeoSupport PAO

Secuencia operativa recomendada para preparar, cargar, validar y publicar imagenes drone en el mosaic dataset y APRX PAO.

Pasos recomendados

1

Confirmar carpeta de entrada y feature de sectores

Verificar que la carpeta de vuelos nuevos y el feature class de indice/footprints esten correctos.

  • Entrada: PATH_INPUT_VUELOS_DRONE.
  • Feature: CL_MLP_PAO_Indice_Vuelos_PAO_IMGS_PO.
  • Campo de sector/llave: Sector y Name.
2

Ejecutar preparacion de salida

Correr 008 Preparacion Salida Carga Mosaico.ipynb.

  • Genera nombres oficiales por fecha y sector.
  • Calcula Path_Destino.
  • Prepara 04_ready_for_datastore.csv y 06_attribute_updates.csv.
  • Revisar 05_review_required.csv antes de avanzar.
3

Validar el manifiesto

Confirmar cantidades y rutas destino antes de tocar datastore o mosaico.

  • Validar que Path_Destino sea correcto.
  • Confirmar que no falten sectores ni fechas.
  • Confirmar que la URL generada tenga la estructura del ImageServer.
4

Cargar al datastore y mosaic dataset

Correr 009 Carga Datastore y Mosaico.ipynb.

  • Primero usar DRY_RUN = True si se cambio la logica.
  • Para carga real usar DRY_RUN = False.
  • El proceso copia al datastore, agrega al mosaico, construye footprints y actualiza atributos.
5

Revisar resultados de carga

Validar el directorio outputs/carga_mosaico/<timestamp>.

  • 00_summary.csv: resumen de estados.
  • 01_load_results.csv: detalle por imagen.
  • 02_errors.csv: debe estar vacio o explicado.
6

Exportar o revisar footprints

Exportar/actualizar geometrias de footprint en GDB cuando se requiera control manual.

  • Usar Name como llave entre mosaic dataset, CSV y feature class.
  • Reordenar/corregir geometria en GDB si corresponde.
  • Evitar duplicados para las imagenes que se normalizaran.
7

Auditar colormap y RGB

Ejecutar la auditoria de TIFF restaurados/cargados.

  • Detectar rasters con has_colormap.
  • Detectar rasters que no sean RGB probable.
  • Guardar 00_audit_colormap_rasters.csv.
8

Normalizar solo los TIFF necesarios

Usar rasterio con el CSV de auditoria y el feature de footprints.

  • Primero: TEST_ONLY_FIRST_IMAGE = True.
  • Validar visualmente el TIFF directo en ArcGIS Pro.
  • Luego procesar todos con TEST_ONLY_FIRST_IMAGE = False.
  • Si se reemplaza en datastore: REPLACE_RASTER_WITH_RGB_CLEAN = True.
  • Si no se quiere backup en datastore: CREATE_BACKUP_BEFORE_RGB_REPLACE = False.
9

Actualizar APRX

Correr 010 Actualizar APRX Imagenes Drone.ipynb.

  • Agrega imagenes al grupo Vuelos Drone PAO > Imagenes Drone.
  • Renombra a formato corto YY_MM_DD_Sector.
  • Ordena de mas nuevas a mas viejas.
  • Guardar primero copia de revision con SAVE_COPY_FOR_REVIEW = True.
10

Validacion final

Revisar mosaico, APRX y rutas fisicas antes de publicar.

  • Verificar que el mosaic dataset muestre las imagenes correctas.
  • Verificar que el TIFF directo se vea como RGB normal si fue normalizado.
  • Confirmar atributos: Sector, Fecha_Adqui, URL, Proyecto, Sensor.
  • Confirmar orden visual en APRX.

Reglas practicas

SituacionAccion recomendada
Una imagen se ve bien en mosaico pero mal como TIFF directo Auditar colormap y normalizar a RGB limpio usando rasterio + footprint.
Se requiere volver al TIFF original Copiar desde path hacia Path_Destino y eliminar sidecars/caches.
El APRX queda con capas fuera de grupo Usar solo el notebook 010, con grupo padre y destino explicitos.
Footprint no se encuentra Revisar que el Name exista una sola vez en el feature class de footprints.
No se quiere duplicar almacenamiento Desactivar backups antes de reemplazar: CREATE_BACKUP_BEFORE_RGB_REPLACE = False.
