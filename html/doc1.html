10. Observaciones Técnicas

  • Las rutas UNC deben mantener la estructura: \\servidor\carpeta\subcarpeta.
  • Las rutas hacia una Feature Class dentro de una File Geodatabase deben incluir: GDB + Dataset + Feature Class, cuando aplique.
  • Las rutas hacia un recurso dentro de una conexión SDE deben incluir: archivo .sde + esquema + nombre del dataset.
  • Se debe validar si cada ruta es de: entrada, proceso, almacenamiento, publicación, respaldo o target productivo.
  • Si el proceso se ejecuta desde servidor o tarea programada, se debe confirmar que el usuario de ejecución tenga acceso a: amssclgis08, amssclgis10 y la conexión SDE hacia amssclgis06.
  • Se recomienda confirmar si existen rutas históricas, rutas vigentes y rutas de producción para no mezclar ambientes.
  • El mosaico target debe validarse desde ArcGIS Pro con la misma cuenta que ejecutará la carga.
