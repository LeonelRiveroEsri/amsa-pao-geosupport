Documento de Validación de Paths - CL_MLP_PAO

Documento para ordenar, revisar y despejar las rutas utilizadas en el flujo de carga, gestión y publicación de imágenes, videos y vuelos drone del proyecto PAO.

1. Objetivo

Este documento tiene como finalidad dejar ordenados los paths principales del flujo CL_MLP_PAO, identificando su uso, tipo de recurso y validaciones necesarias.

Uso recomendado: revisar cada path con la persona encargada del flujo, confirmar permisos de lectura/escritura, validar estructura de carpetas y confirmar qué rutas son de entrada, cuáles son de geodatabase y cuáles son salidas o recursos publicados.

5. Checklist para despejar el flujo

  • Confirmar si el servidor principal de entrada es amssclgis10 y el servidor principal de geodatabases es amssclgis08.
  • Validar permisos de lectura sobre todas las carpetas de vuelos drone.
  • Validar permisos de escritura en la carpeta de entrada: Vuelos_Drone_Sin_Procesar\INPUT.
  • Confirmar si el Excel Parametros_ALL_v3.xlsx es el archivo vigente.
  • Confirmar si el APRX vigente es VISOR TERRITORIAL SIG PAO v7.aprx.
  • Confirmar si la capa de imágenes oblicuas vigente es CL_MLP_PAO_Oblicuas_Drone_v2.
  • Confirmar si el índice de vuelos CL_MLP_PAO_Indice_Vuelos_PAO_IMGS_PO funciona como diccionario, índice espacial o tabla maestra.
  • Confirmar si la capa MLP_SIG_PAO_Videos_Drone está relacionada con los mismos vuelos o corresponde a otro flujo.
  • Confirmar la lógica de nombres de carpetas por zona: Chacay, Chacay_El_Mauro, El_Mauro, El_Mauro_Puerto_Punta_Chungo, Puerto_Punta_Chungo.
  • Confirmar si 26_06 corresponde a fecha de vuelo, fecha de proceso o lote operativo.

7. Observaciones Técnicas

  • Las rutas UNC deben mantener la estructura: \\servidor\carpeta\subcarpeta.
  • Las rutas hacia una Feature Class dentro de una File Geodatabase deben incluir: GDB + Dataset + Feature Class, cuando aplique.
  • Se debe validar si cada ruta es de: entrada, proceso, almacenamiento, publicación o respaldo.
  • Si el proceso se ejecuta desde servidor o tarea programada, se debe confirmar que el usuario de ejecución tenga acceso a: amssclgis08 y amssclgis10.
  • Se recomienda confirmar si existen rutas históricas, rutas vigentes y rutas de producción para no mezclar ambientes.
