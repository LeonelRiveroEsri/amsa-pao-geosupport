GeoSupport - Proceso de carga de imagenes PAO al Mosaic Dataset

Documento de referencia del flujo construido para preparar imagenes de vuelos drone, copiarlas al datastore, cargarlas al mosaic dataset, construir footprints, actualizar atributos, normalizar rasters RGB y actualizar el APRX de publicacion.

Resumen ejecutivo

El proceso automatiza la incorporacion de ortofotos drone al ecosistema SIG PAO. La logica toma una carpeta de entrada, determina el nombre oficial por fecha y sector, copia cada imagen al datastore, la registra en el mosaic dataset, construye el footprint, actualiza campos operativos y deja el APRX ordenado para publicacion.

Preparacion de imagenes

La preparacion se consolido en 008 Preparacion Salida Carga Mosaico.ipynb. El objetivo es producir los CSV que luego alimentan la carga.

Logica aplicada

  • Busqueda recursiva de archivos en la carpeta de entrada.
  • Extraccion de fecha desde el nombre de archivo.
  • Cruce espacial con el feature class de indice de vuelos para determinar el Sector.
  • Si una imagen cruza mas de un sector, se usa el sector con mayor porcentaje de interseccion.
  • El nombre del sector se preserva como viene en la geometria; solo se normalizan espacios cuando aplica.
  • Resolucion de duplicados agregando sufijos secuenciales cuando se repite un nombre esperado.

Exportacion y gestion de geometria de footprints

Una vez cargadas las imagenes y construidos los footprints, se trabajo con una salida de geometria hacia GDB para revisar, ordenar y normalizar los poligonos usados por el proceso.

Objetivo

  • Disponer de un feature class con todas las geometrias de footprint.
  • Usar el campo Name como llave entre raster, mosaic dataset y geometria.
  • Permitir reordenamientos y correcciones de geometria sin alterar la logica de carga.
  • Servir como fuente de corte para normalizaciones RGB cuando un TIFF queda con colormap o interpretacion no compatible.

Fuente consolidada

\\amssclgis08.ams.gmams.cl\CL_MLP_PAO\02_FGDB\CL_MLP_PAO_v1.gdb\CL_MLP_PAO_06_COMPLEMENTOS\CL_MLP_PAO_Indice_Vuelos_PAO_IMGS_PO
Se detectaron nombres duplicados en algunas geometrias historicas. El proceso no corta si para el Name objetivo no existe exactamente una geometria. Esto evita aplicar un footprint equivocado.

Normalizacion RGB y control de colormap

Durante las pruebas se observo que algunos TIFF podian verse bien dentro del mosaic dataset pero mal al abrirse como raster directo. Esto se asocio a colormap, banda unica paleteada, banda alfa o metadatos TIFF interpretados de forma distinta por ArcGIS Pro.

Auditoria

  • Se genero una auditoria con arcpy.Describe para revisar bandCount, pixelType, compresion y colormap.
  • Los resultados se guardan en 00_audit_colormap_rasters.csv.
  • La lista resultante alimenta el reproceso RGB solo para rasters afectados o no RGB.

Normalizacion aplicada

  • Se usa rasterio.mask para cortar con el footprint.
  • Si el raster tiene tres o mas bandas, se escriben bandas 1, 2 y 3 como RGB.
  • Si el raster tiene una banda con colormap, se expande a tres bandas RGB uint8.
  • La salida se escribe como GeoTIFF RGB limpio con photometric="RGB", interleave="pixel" y compress="LZW".
  • Se puede reemplazar el TIFF del datastore sin backup cuando se requiera evitar duplicados, o conservar backup si se desea trazabilidad.
REPLACE_RASTER_WITH_RGB_CLEAN = True
CREATE_BACKUP_BEFORE_RGB_REPLACE = False
PROCESS_ONLY_COLORMAP_OR_NOT_RGB = True

Controles y recomendaciones

  • Validar siempre 05_review_required.csv antes de ejecutar una carga real.
  • Ejecutar primero en modo prueba cuando se cambie la logica de normalizacion RGB.
  • No recortar nuevamente sobre un TIFF ya normalizado si se requiere restaurar el origen; copiar desde path hacia Path_Destino.
  • Eliminar sidecars del destino cuando se restaura un TIFF: .aux.xml, .ovr, .msk, .rrd.
  • Para publicar, trabajar primero con saveACopy del APRX y solo guardar el original cuando la jerarquia y orden sean correctos.
  • El Name debe ser la llave consistente entre CSV, mosaic dataset y feature class de footprints.
